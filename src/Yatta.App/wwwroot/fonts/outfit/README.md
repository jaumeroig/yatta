# Outfit

Variable font (weights 100–900), bundled for offline use in all Yatta Blazor views.

- Theme: https://tweakcn.com/themes/cmmdxhg6d000804l5f6xlcbh3
- Source: https://github.com/google/fonts/tree/main/ofl/outfit
- Original filename: `Outfit[wght].ttf`
- License: SIL Open Font License 1.1; see `OFL.txt`.

`wwwroot/css/fonts.css` registers the font. The `--font-sans` token in
`wwwroot/css/theme.css` selects it for application styles and Blazor Blueprint.
Files under `wwwroot` are included by the Razor SDK when publishing the app.

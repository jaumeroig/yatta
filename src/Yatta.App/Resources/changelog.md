# Historial de versiones

## v1.2.0 12/05/2026
- Posibilidad de especificar en las actividades el código de tarea de Jira.
- Mostrar el código de tarea de Jira en la lista de actividades.
- Ahora el selector de actividad permite realizar búsquedas por nombre de actividad o código de tarea de Jira.
- Se ha cambiado el método de selección de ubicación (oficina o teletrabajo) por una simple casilla de verificación "Teletrabajo" que, cuando está marcada, indica que la actividad se realiza en teletrabajo.

## v1.1.0 09/04/2026
- Prueba de actualización automática.
- Correcciones menores.

## v1.0.0 09/04/2026

### 🚀 Lanzamiento inicial
- Control de tiempo con actividades personalizables
- Gestión de jornada laboral con franjas horarias
- Soporte para teletrabajo y oficina
- Estadísticas mensuales de trabajo
- Notificaciones de recordatorio personalizables
- Soporte multiidioma (Español y Català)
- Temas claro, oscuro y del sistema
- Minimizar a la bandeja del sistema
- Inicio automático con Windows
